## 已確認的方向

- 模型畫面是主角：白色背景、淡而細的網格、模型在網格中央。Header、文字、側欄與控制元件都比舊版小。
- 左側只保留一個本機模型載入按鈕，供 GLB／USD／FBX 使用；現成場景仍可從精簡清單選取。材質隨模型自動顯示，不再另設「套用材質」按鈕。
- 右側配置可拖曳的視角旋鈕、四向平移鍵、重設視角與 `360° 展示`。展示時繞水平軸方位完整旋轉，保持啟動時的俯仰角與鏡頭距離。
- **原圖之外的已確認補充：**Header 右側顯示目前開啟的檔名。沒有開啟檔案時不顯示假檔名；長檔名應截斷但可查閱完整名稱。
- **使用者後續補充：**旋鈕參考 Blender 的六軸導覽球，由 X、Y、Z、−X、−Y、−Z 六個小球組成；正軸以紅、綠、藍實心球標示，負軸以對應顏色的空心球標示。小球位置反映目前鏡頭方向，點選可切換軸向視角。原圖中的大球外觀由此補充取代；右側控制區的整體位置與尺寸不變。

這是設計基準；程式已依原圖與上述兩項補充完成本機版面實作，尚未發布到公開網站。若瀏覽器檔案存取限制使外部 USD 貼圖無法只靠一次選檔自動取得，介面必須明示缺少貼圖並保留色彩備援，不可把缺貼圖說成完整載入成功。

後續 [Issue #5 規格](../spec/issue-5-user-selected-scenes-and-materials.md) 修正了原圖的場景清單來源：清單只反映使用者本次選取的模型，不預載沙崙或部署端清單；位置與精簡比例仍沿用原圖。
